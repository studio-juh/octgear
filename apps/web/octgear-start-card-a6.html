ご購入ありがとうございます。接続、初期操作、キー設定、Firmware更新、困ったときの確認方法をWebで案内しています。

Start Guide QRコードを読み取るか、URLを開きます https://studio-juh.github.io/octgear/octgear-start.html 専用driverは不要です。ページ右上からEnglishへ切り替えられます。
  1. USBで接続 — データ通信対応のUSB Type-Cケーブルを使用します。
  2. ガイドを開く — キーとEncoderの初期操作を確認します。
  3. 自分用に設定 — ChromeまたはEdgeでRemapperへ接続します。
