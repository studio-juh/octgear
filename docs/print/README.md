# Print Materials

頒布物へ同梱する印刷用データです。A6カードはGitHub Pagesへ公開しますが、Homeや各ツールからはリンクせず、検索避けの`noindex`を設定します。URLを知っていれば誰でも閲覧できるため、秘密情報は掲載しません。

## OctGear Start Guide Card

印刷用の[`octgear-start-guide-a6.pdf`](../../apps/web/public/print/octgear-start-guide-a6.pdf)はA6縦・1ページで生成済みです。[`octgear-start-card-a6.html`](../../apps/web/octgear-start-card-a6.html)が編集用sourceです。

公開先:

- HTML: `https://studio-juh.github.io/octgear/octgear-start-card-a6.html`
- PDF: `https://studio-juh.github.io/octgear/print/octgear-start-guide-a6.pdf`

HTMLからPDFを再生成または直接印刷する場合は、browserで開いて次の条件を使用します。

- 用紙: A6
- 向き: 縦
- 倍率: 100%
- 余白: なし
- ヘッダーとフッター: なし
- 背景のグラフィック: 有効

QRコードと印刷されたURLが`https://studio-juh.github.io/octgear/octgear-start.html`を開くことを、入稿・印刷前に実機で確認してください。
